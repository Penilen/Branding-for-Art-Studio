# Art Studio Branding & Advertising Materials
Overview

This project involved creating a complete visual identity and promotional materials for a small art studio.

The goal was to design a cohesive brand system including logo, brochure, and business card, ensuring visual consistency across all materials.

Project Scope

The project includes:

Custom logo design (logo.svg)

Printed brochure (brosura.pdf)

Business card design (vizitka.pdf)

Source design files (.pub formats)

Objectives

Develop a recognizable and consistent visual identity

Apply principles of typography, color theory, and layout

Create print-ready marketing materials

Ensure branding consistency across formats

Design Focus

Clean and minimal layout

Balanced typography hierarchy

Consistent color palette

Readability in both digital and print formats

Alignment between logo and printed materials

Tools Used

Microsoft Publisher

Vector graphics (SVG)

Print-ready PDF formatting

What I Learned

Building a cohesive visual identity system

Applying layout and spacing principles effectively

Preparing assets for print production

Maintaining design consistency across multiple materials

Notes

This project focuses on visual design and branding rather than programming.
It demonstrates creative thinking and the ability to deliver a complete small-scale brand identity system.
